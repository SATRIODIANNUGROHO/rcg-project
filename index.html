Backup & Manajemen Data

Fitur pemeliharaan basis data, export-import, dan auto backup sistem timbangan

1. Export & Cadangkan Data

Unduh cadangan data transaksi, activity log, dan konfigurasi aplikasi dalam basis data SQLite murni (.sqlite) atau format file JSON.

2. Pulihkan & Impor Data

Impor berkas database SQLite (.sqlite), cadangan JSON, atau pulihkan data dari slot auto-backup lokal otomatis terakhir.

3. Zona Bahaya (Reset Data)

Menghapus seluruh rekaman data transaksi penimbangan secara permanen. Pastikan Anda telah melakukan export backup sebelum mengeksekusi tindakan ini.

4. Hak Akses & Manajemen Pemakai

Kelola daftar pemakai sistem, tambahkan akun baru, ubah kata sandi, dan atur matriks kewenangan hak akses secara terperinci.
